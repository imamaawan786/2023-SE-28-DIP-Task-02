# 2023-SE-28-DIP-Task-02
Task 2
"This repository contains a Python-based implementation of Digital Image Processing (DIP) techniques to segment and count objects in an image. Using OpenCV and Matplotlib, the project demonstrates a complete pipeline from image preprocessing to object identification using Connected Component Labeling (CCL).
Key features:
Color Space Conversion (BGR to RGB).
Image Binarization using Global Thresholding.
Noise reduction and Object Masking.
Automated Object Counting using cv2.connectedComponents.".
